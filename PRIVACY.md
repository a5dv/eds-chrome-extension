# Privacy Policy

AIMS Better Experience is a Chrome extension for the AIMS faculty portal (`aims1.eac.edu.ph`).

## Data that the extension collects

The extension collects no personal data. It has no server and sends no data to the developer or to other parties.

## Data that the extension uses

- The extension reads grades and attendance values that you paste into AIMS pages.
- It sends these values only to AIMS, with the same requests that the AIMS pages use.
- It keeps one setting, the paste direction, in the Chrome storage of your browser.

## Publish workflow

The GitHub Actions workflow of this repo uses a Google OAuth app only to upload new versions to the Chrome Web Store. It does not access data of other users.
